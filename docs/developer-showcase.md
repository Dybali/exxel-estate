# Developer presentation examples

The homepage includes a photographic project showcase with three explicitly fictional, sample construction companies. The company directory and each example company profile use the same data and links.

- Akdeniz Atlas Yapı — Bahçe Yaşam Villaları — Antalya
- Ege Form Yapı — Ege Teras Evleri — İzmir
- Marmara Kent Proje — Kent Panorama — İstanbul

These names and projects are illustrative presentation content, not verified businesses, paid advertisements or sales offers. Labels are visible on the promotional cards, company cards and detail pages, with explanatory copy translated into the site's six UI languages. Project names remain proper names. No invented prices, sales claims, delivery dates, customer accounts or real property listings are seeded. Existing archived demo listings remain unpublished. Real company approval and authorization checks are preserved.

Data is maintained in `data/developer-showcase.json`; sample profiles are exposed through the existing company API. Images are local, optimized WebP files totaling approximately 325 KB, lazy-loaded with explicit dimensions. The Next frontend has matching components and assets.
